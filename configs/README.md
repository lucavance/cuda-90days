# Shared Configurations / 通用配置

**English:** This directory stores shared configuration templates for runtimes,
models, and benchmarks.

**中文：** 本目录用于保存 runtime、model、benchmark 的通用配置模板。

**English:** Place configurations dedicated to one benchmark in
`benchmarks/configs/` instead.

**中文：** 单次 benchmark 的专用配置优先放在 `benchmarks/configs/`。
