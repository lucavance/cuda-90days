# Models / 模型

**English:** This directory records architecture, deployment constraints, VRAM
requirements, runtime support, and benchmark observations for the DeepSeek
model family.

**中文：** 本目录记录 DeepSeek 系列模型的结构、部署约束、显存需求、runtime
支持情况和 benchmark 观察。

**English:** Model weights are not stored here; only experiment
configurations, commands, results, and analyses are retained.

**中文：** 本仓库不存放模型权重，只记录实验配置、命令、结果和分析。

## Suggested Content / 建议记录内容

- Model architecture and parameter count / 模型结构与参数规模
- Tokenizer and input/output formats / tokenizer 与输入输出格式
- Weight format and download location / 权重格式与下载位置
- Minimum VRAM requirement / 最小显存需求
- Supported runtimes and frameworks / 支持的 runtime 与 framework
- Benchmark results / benchmark 结果
- Kernel- or runtime-related observations / kernel 或 runtime 相关观察
