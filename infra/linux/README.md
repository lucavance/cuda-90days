# Linux Supporting Skills / Linux 支撑能力

**English:** The current experiment environment uses Ubuntu. This directory
records only Linux skills that support CUDA kernel development and AI inference
infrastructure.

**中文：** 当前实验环境使用 Ubuntu。本目录只记录服务于 CUDA kernel 开发与 AI
推理基础设施的 Linux 能力。

## Scope / 关注范围

- Installing and troubleshooting NVIDIA drivers, the CUDA Toolkit, cuDNN, and related GPU tooling / NVIDIA Driver、CUDA Toolkit、cuDNN 等 GPU 开发环境的安装与排查
- Profiling with `nvidia-smi`, Nsight Systems, and Nsight Compute / 使用这些工具进行 profiling
- Dynamic-library paths, permissions, device files, and container GPU access / 动态库路径、权限、设备文件与容器 GPU 访问
- System observation with `perf`, `htop`, `numactl`, `lscpu`, and `lsblk` / 使用这些工具观察系统
- Shell scripting and experiment-environment automation / Shell 脚本与自动化实验环境

## Non-Goal / 非目标

**English:** This is not a general Linux introduction and does not
systematically cover basic commands, distribution tips, or desktop setup.

**中文：** 本目录不作为通用 Linux 入门教程，不系统记录基础命令、发行版使用
技巧或桌面环境配置。
