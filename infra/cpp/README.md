# C++ Supporting Skills / C++ 支撑能力

**English:** This directory supports CUDA C++ kernel development and records
the necessary C++ engineering skills and low-level mechanisms.

**中文：** 本目录服务于 CUDA C++ kernel 开发，记录必要的 C++ 工程能力与底层
机制。

## Scope / 关注范围

- CMake and CUDA project organization / CMake 与 CUDA 工程组织
- Compilation, linking, ABI, and runtime libraries / 编译、链接、ABI 与运行时库
- Pointers, references, object lifetimes, and RAII / 指针、引用、对象生命周期与 RAII
- Templates and CUDA host/device code organization / 模板与 CUDA host/device 代码组织
- CPU/GPU memory-model differences / CPU/GPU 内存模型差异
- FFI boundaries with Rust / 与 Rust 的 FFI 边界

## Non-Goal / 非目标

**English:** This is not a complete C++ curriculum. It records only concepts
that directly affect CUDA development, kernel debugging, performance
optimization, or cross-language integration.

**中文：** 本目录不作为完整 C++ 语言学习路线，只记录会直接影响 CUDA 开发、
kernel 调试、性能优化和跨语言集成的内容。
