# Python Tooling Layer / Python 工具层

**English:** Python is the experiment-tooling layer for constructing baselines,
validating results, processing benchmark data, and creating visualizations.

**中文：** Python 在本仓库中定位为实验工具层，用于构造 baseline、校验结果、
整理 benchmark 数据和可视化。

## Scope / 关注范围

- PyTorch baselines / PyTorch baseline
- Input-data generation / 输入数据生成
- CUDA/Rust kernel correctness checks / CUDA/Rust kernel correctness check
- Benchmark-result parsing / benchmark 结果解析
- Charting and experiment-report generation / 图表绘制与实验报告生成

## Non-Goal / 非目标

**English:** Python is not the repository's primary implementation language,
and this directory does not provide a separate general Python curriculum.

**中文：** Python 不作为本仓库的主线实现语言，本目录不单独展开通用 Python
学习路线。
